# 栀情屿 ZhiQingYu

面向日常交流的聊天应用，支持对话、记忆、日记、表情、语音及模型配置。

## 快速体验

需要 Python 3。运行内置演示模型，不需要 API 密钥：

```sh
python local-run.py --demo
```

打开终端提示的本地地址，通常为 http://127.0.0.1:8092/。Windows 也可运行 `scripts/start-local-demo.bat`。

使用真实模型时，运行 `python local-run.py`，按提示在 `backend-live/.env.local` 中填写自己的 API 密钥，再重新启动。配置文件和本地数据不会提交到 Git。

## 项目结构

- `frontend/`、`backend-live/`：当前的前后端实现。
- `prototype-frontend/`、`prototype-backend/`：Vue 和 FastAPI 原型。
- `scripts/`：本地启动和依赖安装脚本。

不要将 API 密钥、用户数据、数据库或运行环境文件提交到公开仓库。

## 部署安全

本服务面向单用户使用。公网部署必须在反向代理前启用身份验证和 HTTPS；后端默认只监听本机。`backend-live/nginx-zhiqingyu.conf` 示例要求使用 `/etc/nginx/zhiqingyu.htpasswd`，部署前请使用 `htpasswd` 创建密码文件，配置 HTTPS，再检查并重载 nginx。不要将后端端口直接暴露到公网。

模型连接测试仅在地址与已保存配置一致时复用该地址的密钥；测试新地址时须输入对应密钥。

云端同步使用版本校验，检测到其他设备修改或网络失败时会停止覆盖，保留本机内容并提示先导出备份。确认备份后，可刷新页面读取云端版本。切换到新的模型服务地址时，请同时填写该服务对应的密钥。

反向代理部署须设置 `ZQY_ALLOWED_HOSTS=你的域名`，并设置 `ZQY_TRUST_PROXY=1`（仅接受回环地址代理提供的协议头）。直接本地运行默认仅接受 localhost、127.0.0.1 和 ::1。多个域名用逗号分隔。

未同步内容按标签页独立保存，刷新原标签页会优先恢复其待同步快照；JSON 备份的 `pending_tabs` 字段同时保留其他标签页尚未同步的快照。

备份导入检测到 `pending_tabs` 时会列出主备份及每份待同步快照，可逐份选择并恢复或合并。待同步快照只恢复其中的会话、日记和设置，不套用主备份的记忆。正常聊天与连接测试都不会自动跟随模型服务的重定向，请直接配置最终 API 地址。

服务未配置模型密钥时仍可启动，请在设置中填写；聊天请求会提示缺少配置。合并备份保留双方消息、不应用删除；同一消息内容冲突时另存完整的备份会话副本。浏览器存储空间不足且云端保存失败时，请保持页面打开并立即导出备份。

模型设置采用加锁和原子替换保存；部分更新保留未提供的备用模型配置，显式传入 `fallbacks: []` 才会清空。请求体读取最多等待 30 秒，分块元数据累计限制为 64 KiB、单行限制为 8 KiB。历史消息合并同时保留原顺序和可兼容的备份顺序；顺序冲突时另存备份会话副本。

切换或删除会话会停止对应生成请求，已有的半截回复保留在原会话；延迟失败的插话也会回到原会话。模型和语音等上游响应受大小限制，gzip 解压后的内容同样计入限制，异常响应会明确失败。

记忆备份合并使用服务端 `merge` 操作，在同一个锁内读取并合并，避免前端读后整表覆盖导致丢失实时新增记忆；结构化备份也可安全导入旧格式记忆。日记生成会核对原始对话及数据集，清空、恢复或修改源对话后的旧结果不会重新写入。

聊天超时按无活动时间计算：收到流数据即重置，支持服务端模型顺延和提问卡片等待；另有 30 分钟总时长上限。代理示例需包含在现有 HTTPS `server` 块内，部署前执行 `nginx -t`。

清空/替换记忆会使旧对话的记忆写入失效，防止已清除的事实被旧模型结果恢复。AI 生成的人设预设会立即持久化；清空操作会检查记忆与共同回忆的返回结果，部分失败时保留本机数据并明确提示。

归档导入先校验所有可识别条目，再开始写入；空包、无可恢复数据、重复条目或损坏内容会报错。导出遇到不可读取的数据也会失败，不会生成静默缺项的备份。旧格式 `.md` 记忆会包含在归档中，恢复时同步 JSON 和兼容镜像，保留历史长条目和条目数。

同一会话的重叠生成会明确拒绝；插话先保存在本机，队列满或回合收尾后转入下一轮，避免跨回合串话和静默丢失。

归档恢复会暂停页面自动同步，成功后重新读取云端版本；恢复期间有本地编辑时会保留本机内容并暂停覆盖。JSON 备份固定导出点击时的会话/身份快照，读取不到长期记忆时会标注 `memory_status.available=false`，不会伪装完整备份。损坏的待同步快照也会保留原文以供恢复。

模型设置或会话文件损坏时不会静默退回默认服务/空库。重新填写完整服务地址、模型和密钥可修复设置；归档导入会要求确认后修复会话存储。修复前的损坏文件保存在同目录下的私有 `.bak` 文件中，不会进入 Git。

记忆编辑/删除按稳定 ID 定位，失败后不再改用旧下标或整表覆盖；旧格式列表编辑会检查读取时的快照，列表变化时要求刷新。切换身份或重叠刷新时，过期的记忆列表和确认操作不会作用到另一身份。

记忆文件损坏时不会自动用旧镜像重建或当作空表；页面显示读取失败，普通写入停止。确认用归档覆盖修复时，先在记忆目录保留私有 `.zqy-memory-corrupt-*.bak` 原件。JSON/归档恢复、旧格式迁移、读取计数和置顶等操作会保留完整条目数与已有长文本。
